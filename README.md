# Немного о тебе

Небольшой сайт с 40 необязательными вопросами в восьми темах. Нежно-розовое оформление, белый кружевной орнамент, выбор цветов по фотографиям и финальный стих.

## Ответы

Ответы сохраняются в localStorage браузера на текущем устройстве. Серверной базы, аналитики и автоматической отправки ответов нет. В конце можно скачать TXT или JSON, скопировать текст либо вызвать системное меню отправки. Полученный файл нужно самостоятельно отправить в личном сообщении. JSON содержит тексты вопросов, выбранные варианты, дополнения и отдельные статусы: `answered`, `unknown`, `skipped`, `not-viewed`.

Кнопка «Пропустить» очищает текущий ответ и записывает пропуск; «Пока не знаю» записывает отдельный статус. Простое переключение темы сохраняет введённое. В приватном режиме или при очистке данных браузера прогресс может исчезнуть.

Экспорт не зашифрован. Не загружайте реальные ответы в этот репозиторий, Issues или публичные комментарии. Для разбора достаточно отправить один TXT или JSON в приватный чат.

## Запуск

Сайт не требует сборки и зависимостей. Для локального просмотра: `python -m http.server 4173 --bind 127.0.0.1`, затем открыть `http://127.0.0.1:4173/`.

GitHub Pages: Settings → Pages → Deploy from a branch → `main` → `/ (root)`.

## После прохождения

После получения файла с ответами отключите публикацию в Settings → Pages (ветка `None`), затем Settings → General → Danger Zone → Change repository visibility → Private. Одна только приватность репозитория не гарантирует отключение Pages на платных планах. У сайта нет автоматического сигнала о прохождении: ответы намеренно не отправляются на сервер.
